# Plata · legacy

Recuerdo de la **primera versión guardada** de la app, del 17 de octubre de 2026, cuando todavía se llamaba «Finanzas».

- Cuatro pestañas: Resumen, Deuda, Proyección y Movimientos.
- Arranca con datos de ejemplo.
- Colores azul y naranja, sin marca Plata.

Es solo un archivo de recuerdo: no se actualiza ni se publica. La app actual vive en las ramas `main` (beta) y `alpha`.

Abre `index.html` en un navegador para verla.
